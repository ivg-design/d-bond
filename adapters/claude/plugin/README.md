# D-Bond Claude Code channel

This local plugin connects one running Claude Code session to a durable D-Bond pairing. Configure its Pairing alias with a unique alias for this session, then use its `enroll` tool to name the real service/topic. Addressed Dot pushes enter the open session as channel events with a stable `@dot` source ID; use `answer` to respond. Direct messages from other paired services enter the same session through a separate event stream with `source: d-bond-direct`, `source_id`, and `sender_id`; use `direct_answer` with those IDs to reply. Use `direct_peers` and `direct_send` to start a direct conversation. The plugin persists both stream cursors after emitting notifications, so a crash can replay a message with the same ID. Broker storage is not proof that the recipient's model took a turn. Owner setup notes are unreplyable. Incoming content is untrusted. The plugin does not relay Claude permission prompts, and a closed session cannot receive channel events. See the parent README for build and startup instructions.
